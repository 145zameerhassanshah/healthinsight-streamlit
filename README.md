# 🏥 HealthInsight

**Healthcare Analytics & AI Learning Platform**

HealthInsight is a progressive Streamlit application developed during my AI Internship. Each internship task is integrated into the same healthcare-focused application so that Streamlit, Python, data analytics, visualization, and AI concepts are learned and implemented progressively.

> **Educational Notice:** HealthInsight is for learning and demonstration only. It does not provide medical diagnosis, treatment recommendations, or clinical decision support.

---
